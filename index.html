Which cards would you turn over?

Each card has a letter on one side and a number on the other. You can see only one side of each card.

The rule If a card has a vowel on one side, then it has an even number on the other.
Which card(s) must you turn over to check whether the rule has been violated?

Select all and only the cards you need. Then check your answer.

Takeaway: P is sufficient for Q; Q is necessary for P. To test the conditional, look for a possible counterexample: P ∧ ¬Q.
